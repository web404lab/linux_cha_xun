pmap

pmap命令

功能描述

pmap命令来自英文词组“process memory map”的缩写，其功能是用于显示进程的内存映像信息。pmap命令能够显示进程映像的起始地址、虚拟内存大小、进程访问地址空间的权限以及内存映像文件等信息，而我们只需告知进程号码即可。

语法

pmap [参数] [进程ID]

参数说明

  • -c 读取默认配置
  • -d 显示内存映射文件的偏移值、主次设备号等信息
  • -h 显示帮助信息
  • -n 创建新的配置
  • -N 创建新的配置并保存到文件
  • -p 显示文件的完整路径
  • -q 静默执行模式
  • -V 显示版本信息
  • -x 显示物理内存大小、未同步磁盘页面数量等信息
