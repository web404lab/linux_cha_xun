sshd

sshd命令

功能描述

sshd命令来自英文词组“SSH daemon”的缩写，其功能是用于openssh服务器守护进程。openssh套件能够为两台主机之间建立加密的、可信任的数据通信服务，是rlogin与rsh等明文数据通信的替代品，而sshd命令即为openssh套件中的核心程序。

语法

sshd [参数] [对象]

参数说明

  • -4 基于IPv4网络协议
  • -6 基于IPv6网络协议
  • -d 使用调试模式
  • -D 使用非后台守护进程的方式运行服务
  • -e 直接显示报错信息
  • -f 设置服务器的配置文件
  • -g 设置客户端登录的过期时间
  • -h 设置读取主机密钥文件
  • -i 使用inetd方式运行
  • -o 设置服务配置选项
  • -p 设置使用的端口号
  • -q 静默执行模式
  • -t 使用测试模式
