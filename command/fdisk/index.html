fdisk

fdisk命令

功能描述

fdisk的意思是固定磁盘（fixed disk）或格式化磁盘（format disk），该命令的功能是管理磁盘的分区信息。

fdisk命令可以用来对磁盘进行分区操作，用户可以根据实际情况对磁盘进行合理划分，这样后期挂载和使用时会方便很多。

语法

fdisk [参数] [设备名]

参数说明

  • -b 设置每个分区的大小
  • -c 关闭DOS兼容模式
  • -C 设置硬盘的柱面数量
  • -h 显示帮助信息
  • -H 设置硬盘的磁头数
  • -s 显示指定的分区大小
  • -S 设置每个磁道的扇区数
  • -u 以分区数目代替柱面数目
  • -v 显示版本信息
