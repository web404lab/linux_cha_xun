dhclient

dhclient命令

功能描述

dhclient命令来自英文词组DHCP client的缩写，其功能是动态获取或释放IP地址。使用dhclient命令前，需要将网卡模式设置成DHCP自动获取，否则静态模式的网卡不会主动向服务器获取如IP地址等网卡信息‍。

语法

dhclient [参数] [网卡名]

参数说明

  • -4 基于IPv4网络协议
  • -6 基于IPv6网络协议
  • -d 以前台方式运行
  • -F 设置向DHCP服务器发送的FQDN
  • -H 设置向DHCP服务器发送的主机名
  • -n 不配置任何接口
  • -p 设置DHCP客户端监听的端口号
  • -q 静默执行模式
  • -s 在获取IP地址前指定DHCP服务器
  • -v 显示执行过程详细信息
  • -V 设置要发送给DHCP服务器的厂商类标识符
  • -w 即使没有找到广播接口，也继续运行
  • -x 停止DHCP客户端，而不释放当前租约
  • --timeout 设置最大响应超时时间
  • --version 显示版本信息

参考示例

示例1:
通过指定网卡发起DHCP请求，获取网卡参数： [root@linuxcool ~]# dhclient ens160
示例2:
释放系统中已获取的网卡参数： [root@linuxcool ~]# dhclient -r Killed old client process
示例3:
向指定的服务器请求获取网卡参数： [root@linuxcool ~]# dhclient -s 192.168.10.10
示例4:
手动停止执行dhclient服务进程： [root@linuxcool ~]# dhclient -x Removed stale PID file
