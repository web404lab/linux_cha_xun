cpupower

cpupower命令

功能描述

cpupower命令的功能是调整CPU主频参数。Linux系统内核支持根据使用场景来调节CPU主频参数，以提高计算性能或降低功耗。

对于移动设备来讲，在没有接通电源的时候，续航是很重要的，此时就可以启用CPU休眠功能。而服务器一直接着电源，而且需要具有很强的性能，此时就应禁止CPU休眠功能，并把CPU主频固定到最高值。

语法

暂无语法

参数说明

  • frequency-info 显示主频信息
  • frequency-set 设置主频模式
  • -c 指定要显示的内核列表
  • --help 显示帮助信息

参考示例

示例1:
查看当前CPU的全部主频信息： [root@linuxcool ~]# cpupower -c all frequency-info
示例2:
设置当前CPU为性能模式： [root@linuxcool ~]# cpupower -c all frequency-set -g performance
示例3:
设置当前CPU为节能模式： [root@linuxcool ~]# cpupower -c all frequency-set -g powersave
示例4:
查看CPU主频信息： [root@linuxcool ~]# cpupower frequency-info
