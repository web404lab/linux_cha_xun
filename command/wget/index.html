wget

wget命令

功能描述

wget命令来自英文词组web get的缩写，其功能是从指定网址下载网络文件。wget命令非常稳定，一般即便网络发生波动也不会导致下载失败，而是不断地尝试重连，直至整个文件下载完毕。

wget命令支持如HTTP、HTTPS、FTP等常见协议，可以在命令行中直接下载网络文件。

语法

wget [参数] [网址URL] [对象]

参数说明

  • -4 基于IPv4网络协议
  • -6 基于IPv6网络协议
  • -a 将日志追加写入至指定文件
  • -b 启动后转入后台执行
  • -c 支持断点续传
  • -d 使用调试模式
  • -e 执行指定的命令
  • -F 将输入文件当作HTML处理
  • -h 显示帮助信息
  • -i 下载指定文件中的链接
  • -l 设置最大递归目录深度
  • -nd 不要创建目录
  • -N 只获取比本地更新的文件
  • -o 将日志信息写入指定文件
  • -O 设置本地文件名
  • -P 设置文件前缀
  • -q 静默执行模式
  • -S 显示服务器响应信息
  • -t 设置最大尝试次数
  • -T 设置最长等待时间
  • -v 显示执行过程详细信息
  • -V 显示版本信息
  • -w 设置等待间隔（秒）
  • -x 强制创建目录
  • --ask-password 提示输入密码
  • --limit-rate 限制下载速度
  • --no-dns-cache 关闭DNS查询缓存
  • --no-proxy 禁止使用代理
  • --password 设置密码值
  • --random-wait 下载多个文件时，随机等待间隔（秒）
  • --spider 仅检查文件是否存在
  • --user 设置用户名

示例2:
下载指定的网络文件，并定义保存在本地的文件名称： [root@linuxcool ~]# wget -O Book.pdf https://www.linuxprobe.com/docs/LinuxProbe.pdf

示例4:
启用断点续传技术下载指定的网络文件： [root@linuxcool ~]# wget -c https://www.linuxprobe.com/docs/LinuxProbe.pdf
示例5:
下载指定的网络文件，将任务放至后台执行： [root@linuxcool ~]# wget -b https://www.linuxprobe.com/docs/LinuxProbe.pdf Continuing in background, pid 237616. Output will be written to ‘wget-log’.
