redis-benchmark

redis-benchmark命令

功能描述

redis-benchmark命令可以为Redis做基准性能测试，它提供了很多选项帮助开 发和运维人员测试Redis的相关性能。

语法

redis-benchmark [参数]

参数说明

  • -h 服务端IP
  • -p 服务器端口
  • -a redis密码
  • -c 客户端连接数量
  • -n 请求总数

参考示例

示例1:
使用默认配置对127.0.0.1:6379运行基准测试： [root@linuxcool ~]# redis-benchmark
示例2:
对192.168.1.1使用20个并行客户端，总共10万个请求： [root@linuxcool ~]# redis-benchmark -h 192.168.1.1 -p 6379 -n 100000 -c 20
示例3:
仅使用SET测试，用大约100万个键填充127.0.0.1:6379： [root@linuxcool ~]# redis-benchmark -t set -n 1000000 -r 100000000
示例4:
基准127.0.0.1:6379，用于生成CSV输出的几个命令： [root@linuxcool ~]# redis-benchmark -t ping,set,get -n 100000 --csv
示例5:
对特定命令行进行基准测试： [root@linuxcool ~]# redis-benchmark -r 10000 -n 10000 eval 'return redis.call("ping")' 0
示例6:
用10000个随机元素填充列表： [root@linuxcool ~]# redis-benchmark -r 10000 -n 10000 lpush mylist rand_int
