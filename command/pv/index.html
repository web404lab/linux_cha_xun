pv

pv命令

功能描述

pv命令来自于英文词组”Pipe viewer“的缩写，其功能是用于管道查看器。pv命令能够通过管道显示数据处理进度信息，包含已经耗费的时间、完成百分比、当前速度、全部传输的数据以及预估剩余时间等信息。

语法

pv [参数] [文件]

参数说明

  • -p 显示进度条
  • -t 显示任务已经进行的时长
  • -e 显示剩余多长时间完成
  • -r 显示当前传输速率
  • -a 显示平均传输速率
  • -b 显示传输的字节数
  • -F 设置输出格式为format
  • -n 显示进度百分比
  • -q 不输出任何信息
  • -W 在传输第一个字节之前不显示任何内容

参考示例

示例1:
显示与操作有关的有用信息，包括已经传输了的数据量，花费的时间，传输速率，进度条，进度的百分比，以及剩余的时间: [root@linuxcool ~]# pv /media/himanshu/1AC2-A8E3/fNf.mkv > ./Desktop/fnf.mkv
示例2:
使用 -n 选项来允许 pv [命令]显示整数百分比，在标准错误输出上每行显示一个数字，用来替代通常的可视进度条: [root@linuxcool ~]# pv -n /media/himanshu/1AC2-A8E3/fNf.mkv > ./Desktop/fnf.mkv
示例3:
列出存储池中具有特定名称的物理卷，请输入以下命令: [root@linuxcool ~]# pv –list –attr pv_name=hdisk7
示例4:
列出存储池中具有特定名称的物理卷，请输入以下命令: [root@linuxcool ~]# pv –list –attr pv_name=hdisk7 POOL_NAME: testsp TIER_NAME : tier1 FG_NAME : fg2 PV_NAME SIZE(MB) STATE UDID hdisk7 10240 ONLINE 3E213600A0B80006E25060000D2E64F755F420F1828 FAStT03IBMfcp
