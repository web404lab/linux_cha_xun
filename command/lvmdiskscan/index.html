lvmdiskscan

lvmdiskscan命令

功能描述

lvmdiskscan命令的作用是可以在系统中为LVM物理卷扫描所有的SCSI、IDE磁盘、多种设备和其他块设备。

lvmdiskscan命令会扫描所有可见的LVM2设备，而LVM2比LVM1支持了更多的逻辑卷类型，支持了cluster lvm功能，提供了基于文本格式的元数据信息，提供了更多的命令集和操作命令。

lvmdiskscan命令报告的大小就是实际设备的大小。通常还可以通过lvmdiskscan命令来查看那些设备被做成了物理卷。

常用参数：lvmdiskscan [参数]

语法

暂无语法

参数说明

  • -l 只报告物理卷
  • -v 长格式显示
  • -h 帮助
  • -d 调试模式

参考示例

示例1:
扫描可见LVM2所有设备，只报告物理卷： [root@linuxcool ~]# lvmdiskscan -l
示例2:
扫描所有可见LVM2设备： [root@linuxcool ~]# lvmdiskscan
示例3:
扫描可见LVM2所有设备，以长格式显示： [root@linuxcool ~]# lvmdiskscan -v
