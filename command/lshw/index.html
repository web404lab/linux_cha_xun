lshw

lshw命令

功能描述

lshw命令来自英文词组“list hardware”的缩写，其功能是用于查看硬件设备信息。lshw命令能够显示Linux系统中的内存配置、固件版本、主板配置、CPU版本和速度、总线速度等丰富的硬件设备信息。

语法

lshw [参数]

参数说明

  • -C 设置设备类型
  • -X 启动图形界面
  • -businfo 显示总线相关信息
  • -enable test 启动测试模式
  • -html 使用html格式输出结果
  • -help 显示帮助信息
  • -json 使用json格式输出结果
  • -numeric 显示设备的数字ID
  • -quiet 静默执行模式
  • -short 使用简要信息模式
  • -sanitize 移除敏感信息
  • -version 显示版本信息
  • -xml 使用xml格式输出结果
