df

df命令

功能描述

df命令来自英文词组report file system disk space usage的缩写，其功能是显示系统上磁盘空间的使用量情况。df命令显示的磁盘使用量情况含可用、已用及使用率等信息，默认单位为KB，建议使用-h参数进行单位换算，毕竟135MB比138240KB更利于阅读。

语法

df [参数] [对象磁盘/分区]

参数说明

  • -a 显示所有文件系统
  • -h 以更易读的方式显示
  • -H 以1KB=1000B为换算单位
  • -i 显示索引字节信息
  • -k 设置显示时的块大小
  • -t 只显示指定类型文件系统
  • -T 显示文件系统的类型
  • --sync 在获取磁盘使用信息前先执行sync同步命令

参考示例

示例1:
显示系统全部磁盘的使用量情况（带容量单位）： [root@linuxcool ~]# df -h Filesystem Size Used Avail Use% Mounted on devtmpfs 969M 0 969M 0% /dev tmpfs 984M 0 984M 0% /dev/shm tmpfs 984M 9.6M 974M 1% /run tmpfs 984M 0 984M 0% /sys/fs/cgroup /dev/mapper/rhel-root 17G 3.9G 14G 23% / /dev/sr0 6.7G 6.7G 0 100% /media/cdrom /dev/sda1 1014M 152M 863M 15% /boot tmpfs 197M 16K 197M 1% /run/user/42 tmpfs 197M 3.5M 194M 2% /run/user/0
示例2:
显示指定磁盘分区的使用量情况（带容量单位）： [root@linuxcool ~]# df -h /boot Filesystem Size Used Avail Use% Mounted on /dev/sda1 1014M 152M 863M 15% /boot
示例3:
