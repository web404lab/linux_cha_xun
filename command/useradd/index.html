useradd

useradd命令

功能描述

useradd命令的功能是创建并设置用户信息。使用useradd命令可以自动完成用户信息、基本组、家目录等的创建工作，并在创建过程中对用户初始信息进行定制。

针对已创建的用户，则需使用chmod命令修改用户信息，使用passwd命令修改密码信息。

语法

useradd [参数] [用户名]

参数说明

  • -c 添加备注文字
  • -d 设置新用户登录时所使用的家目录
  • -D 设置新用户的预设值
  • -e 设置用户的终止日期
  • -f 设置用户过期几日后永久停权
  • -g 设置用户对应的基本用户组
  • -G 设置用户对应的扩展用户组
  • -h 显示帮助信息
  • -k 设置用户的骨架目录
  • -l 不将用户添加到最近登录和登录失败数据库文件
  • -m 用户目录不存在时则自动创建
  • -n 不建立以用户名称为名的组
  • -o 允许创建重复UID的用户
  • -p 设置用户的密码
  • -r 建立系统用户
  • -R 设置根目录
  • -s 设置新用户的默认Shell终端
  • -u 设置用户ID
  • -U 创建与用户同名的组，并将其加入
  • -Z 设置用户的SELinux映射角色

参考示例

示例1:
创建指定的用户信息： [root@linuxcool ~]# useradd linuxprobe
示例2:
创建指定的用户信息，但不创建家目录，亦不让登录系统： [root@linuxcool ~]# useradd -M -s /sbin/nologin linuxprobe
示例3:
创建指定的用户信息，并自定义UID值： [root@linuxcool ~]# useradd -u 6688 linuxprobe
示例4:
创建指定的用户信息，并追加指定组为该用户的扩展组： [root@linuxcool ~]# useradd -G root linuxprobe
示例5:
创建指定的用户信息，并指定过期时间： [root@linuxcool ~]# useradd -e "2024/01/01" linuxprobe
