arch

arch命令

功能描述

arch命令来自英文单词“architecture”的缩写，中文译为“架构”，其功能是用于显示主机硬件架构类型。虽说目前主流硬件架构当数x86_64应用最广泛，但也会偶尔遇到下载了软件包无法安装的情况，这时就要排除下服务器是不是i386、i486、mips、alpha等架构类型了。

语法

arch [参数]

参数说明

  • --help 显示帮助信息
  • --version 显示版本信息

参考示例

示例1:
显示当前主机硬件架构类型： [root@linuxcool ~]#archx86_64
