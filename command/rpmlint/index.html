rpmlint

rpmlint命令

功能描述

rpmlint命令的作用是可以检查rpm软件包中常见的错误。使用rpmlint命令需要先安装rpmlint软件包。

rpmlint命令可用于在上传之前测试单个软件包或检查整个发行版。默认情况下，将对包进行全面检查，根据需要可以使用参数执行特定的检查。

语法

rpmlint [参数] [文件或软件包]

参数说明

  • -I 未指定的消息标识符显示解释然后退出
  • -v 详细模式
  • -C<目录> 在路径列表的前面插入指定目录，来进行加载检查
  • -a 检查所有已安装的软件包
  • -c 只运行指定的检查
  • -i 显示报告信息的说明
  • -E<目录> 为提取临时文件指定基本目录
  • -n 忽略输出过滤
  • -f<配置文件> 从指定的文件加载用户的配置
  • -o<值> 覆盖配置选项

参考示例

示例1:
检查指定软件包中的错误： [root@linuxcool ~]# rpmlint bind
示例2:
检查所有的已安装软件包： [root@linuxcool ~]# rpmlint -a
示例3:
详细检查所有已安装的软件包： [root@linuxcool ~]# rpmlint -a -v
