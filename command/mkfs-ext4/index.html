mkfs-ext4

mkfs.ext4命令

功能描述

mkfs.ext4命令来自英文词组make filesystem Ext4的缩写，其功能是对磁盘设备进行EXT4格式化操作。

语法

mkfs.ext4 [参数] [设备名]

参数说明

  • -b 设置文件数据块大小
  • -c 格式化前检查分区是否有坏块
  • -E 设置文件系统扩展选项
  • -f 以字节为单位指定片段大小
  • -F 强制格式化而不询问
  • -g 设置一个块组中的块数
  • -i 设置字节和节点的比率
  • -I 设置每个节点的大小
  • -l 读取文件名中的坏块列表
  • -M 设置文件系统的最后挂载目录
  • -o 覆盖文件系统的“创建者操作系统”字段的默认值
  • -O 使用指定的特性创建一个文件系统
  • -q 静默执行模式
  • -t 设置要创建的文件系统类型
  • -U 使用指定的UUID创建文件系统
  • -V 显示版本信息
