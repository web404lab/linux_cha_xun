pstack

pstack命令

功能描述

pstack命令来自英文词组“process stack”的缩写，其功能是用于显示进程的栈跟踪信息。pstack实际上是gstack的一个链接命令，gstack本身是一个由gdb封装的Shell脚本程序，该命令用于显示指定进程的栈追踪信息。pstack命令必须由管理员身份执行，能够准确地定位进程挂起的位置，使用方法非常简单，仅需后面加上进程号码即可。

语法

pstack [参数] [进程号码]

参数说明

  • -d 设置定间隔符（默认为tab）
  • -s 使用串列处理，而非平行处理
  • --help 显示帮助信息
  • --version 显示版本信息
