dig

dig命令

功能描述

dig命令来自英文词组“domain information groper”的缩写，其功能是用于查询域名DNS信息。dig命令能够便捷地查询到指定域名所对应的DNS服务器信息，具有灵活性好，易用，输出清晰等特点，与nslookup命令很相似。

语法

dig [参数] [域名或IP地址]

参数说明

  • @ 设置域名服务器
  • -4 基于IPv4网络协议
  • -6 基于IPv6网络协议
  • -b 设置本机发起请求的IP地址
  • -f 使用批处理模式
  • -h 显示帮助信息
  • -k 指定TSIG密钥文件
  • -p 设置域名服务器所使用端口号
  • -t 设置要查询的DNS数据类型
  • -x 执行反向域名查询
