ssh-copy-id

ssh-copy-id命令

功能描述

ssh-copy-id命令来自英文词组ssh copy id，其功能是将本地生成的SSH公钥信息复制到远程主机。通常情况下，运维人员会先使用ssh-keygen命令生成SSH密钥对（公钥/私钥）文件，随后使用ssh-copy-id命令将公钥文件复制到远程主机上，这样操作后，再进行远程SSH访问时将无须进行账号密码验证，而是通过密钥方式登录。

语法

ssh-copy-id [参数] [域名或IP地址]

参数说明

  • -f 强制复制而不询问
  • -i 设置公钥文件路径
  • -p 设置使用的端口号
