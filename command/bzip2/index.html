bzip2

bzip2命令

功能描述

bzip2命令的功能是压缩或解压缩.bz2文件。Linux系统中常见的以.bz2结尾的文件是由bzip2命令压缩而成的，bzip2是一款压缩算法较新、压缩比较充分的压缩工具，与gzip命令十分相似。

语法

bzip2 [参数] [压缩包.bz2] [文件或目录名]

参数说明

  • -c 显示处理结果
  • -d 执行解压缩操作
  • -f 强制覆盖已有文件而不询问
  • -k 保留已有文件
  • -q 跳过所有警告信息
  • -s 降低内存使用量
  • -v 显示执行过程详细信息
  • -z 执行压缩操作
  • --help 显示帮助信息
  • --version 显示版本信息

参考示例

示例1:
对指定的文件进行压缩操作： [root@linuxcool ~]# bzip2 File.cfg
示例2:
对指定的文件进行压缩操作，并显示详细过程： [root@linuxcool ~]# bzip2 -v File.cfg initial-setup-ks.cfg: 1.524:1, 5.250 bits/byte, 34.37% saved, 1542 in, 1012 out.
示例3:
检查指定压缩包文件的完整性： [root@linuxcool ~]# bzip2 -t File.bz2
示例4:
解压缩指定的压缩包文件： [root@linuxcool ~]# bzip2 -d File.bz2
