rexec

rexec命令

功能描述

rexec命令是远程执行命令服务器的客户端工具，向远程rexec服务器发出执行命令的请求。

rexec命令以客户机/服务器的模式运行。运行rexec命令时首先要启动远程主机上的rexec服务器。

语法

rexec [参数] [远程主机或命令]

参数说明

  • -a 表示远程命令的标准错误与标准输出相同，不支持发送任意信号到远程进程
  • -l<用户名> 指定连接远程rexec服务器的用户名
  • -p<密码> 指定连接远程rexec服务器的密码
  • -n 明确地提示输入用户名和密码

参考示例

示例1:
在远程主机上执行date命令： [root@linuxcool ~]# rexec linuxcool date
示例2:
提示输入用户名和密码执行date命令： [root@linuxcool ~]# rexec -n linuxcool date
示例3:
使用密码执行date命令： [root@linuxcool ~]# rexec -l uesrname -p password linuxcool date
