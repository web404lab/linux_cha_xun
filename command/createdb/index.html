createdb

createdb命令

功能描述

createdb命令来自英文词组“create database”的缩写，其功能是用于创建PostgreSQL数据库。PostgreSQL是一个功能强大的、开放源代码的客户/服务器关系型数据库管理系统，支持灵活的权限管理，能够控制一个角色对某张表的读、写、更新、删除等操作权限，执行某个函数的权限以及操作视图。

语法

createdb [参数] [数据库]

参数说明

  • -D 设置数据库默认表空间
  • -e 显示发送到服务端的命令
  • -E 设置数据库编码
  • -h 设置数据库服务器的主机名
  • -O 设置数据库用户名称
  • -p 设置数据库服务器端口号
  • -T 设置要复制的数据库模版
  • -U 设置连接的用户名
  • -w 永远不提示输入口令
  • -W 强制提示输入口令
  • --help 显示帮助信息
  • --version 显示版本信息

参考示例

示例1:
创建一个指定名称的本地数据库： [root@linuxcool ~]#createdb linuxcool
示例2:
创建一个指定名称的远程数据库： [root@linuxcool ~]#createdb -p 5888 -h 192.168.10.10 linuxcool
示例3:
以原有数据库为模板（linuxcool），创建一个新的数据库（linuxprobe）： [root@linuxcool ~]#createdb linuxprobe -T linuxcool
