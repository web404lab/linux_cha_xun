aumix

aumix命令

功能描述

aumix命令用于设置音效装置。aumix(audio mixer)命令设置各项音效装置的信号强度以及指定播放与录音的装置。

语法

aumix [参数]

参数说明

  • -d 指定音效装置的名称
  • -f 指定存储或载入设置的文件
  • -I 以图形界面方式来执行aumix
  • -q 显示所有频道的设置值
  • -S 将设置值保存至/HOME/.aumixrc

参考示例

示例1:
以简单的图形界面来调整设置频道参数： [root@linuxcool ~]# aumix
示例2:
指定音效设备的名称： [root@linuxcool ~]# aumix -1 -P -d test1
