getfattr

getfattr命令

功能描述

getfattr命令来自英文词组“get extended attributes of filesystem objects”的缩写，其功能是用于获取文件系统扩展属性信息。这里所提及的文件系统扩展属性，并不是用chattr和lsattr命令设置查看的隐藏权限，而是用setfattr命令设置的，一种完全自定义的扩展属性，使用getfattr命令能够获取指定文件及其关联的一组扩展属性信息。

语法

getfattr [参数] [文件名]

参数说明

  • -d 显示所有扩展属性值
  • -e 设置编码值类型
  • -h 不引用符号链接
  • -m 包括名称匹配正则表达式模式的属性
  • -n 显示已命名的扩展属性值
  • -P 跳过所有符号链接
  • -R 递归处理所有子文件
  • --help 显示帮助信息
  • --version 显示版本信息

参考示例

示例1:
获取指定文件的所有扩展属性值： [root@linuxcool ~]#getfattr -d File.cfg
示例2:
通过匹配正则表达式来获取指定目录下的文件及其扩展属性值： [root@linuxcool ~]#getfattr -d -m File.* /Dir
