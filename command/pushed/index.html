pushed

pushed命令

功能描述

pushed命令用于将目录加入堆栈中，加入记录到目录栈顶部，并切换到该目录，如果不加任何参数， 则会将位于记录栈最上面的两个目录对换位置。

语法

pushed [参数] [目录]

参数说明

  • -n 将右起第n个目录移到堆栈顶（n从0开始计数）
  • +n 将左起第n个目录移到堆栈顶（n从0开始计数）

参考示例

示例1:
显示Shell默认的目录堆栈： [root@linuxcool ~]# dirs /var/log
示例2:
向Shell目录堆栈中添加目录/etc： [root@linuxcool ~]# pushed /etc
示例3:
显示Shell目录堆栈内容，每行一个记录，并加序号： [root@linuxcool ~]# dirs -v 0 /sbin 1 /etc 2 /var/log
示例4:
将第一个记录移到堆栈顶： [root@linuxcool ~]# pushed -1 /etc /var/log /sbin
