dmesg

dmesg命令

功能描述

dmesg命令来自英文词组“display message”的缩写，其功能是用于显示开机过程信息。Linux系统内核会将开机过程信息存储在环形缓冲区（ring buffer）中，随后再写入到/var/log/dmesg文件里，如果开机时来不及查看这些信息，则可以利用dmesg命令进行调取。

语法

dmesg [参数]

参数说明

  • -c 清空环形缓冲区中的内容
  • -d 显示信息时间差
  • -D 禁止向终端输出信息
  • -E 启用向终端输出信息
  • -H 以更易读的格式输出信息
  • -k 显示内核信息
  • -l 设置输出级别
  • -L 显示彩色信息
  • -n 设置记录信息的层级
  • -r 显示原生消息缓冲区信息
  • -s 设置环形缓冲区的大小
  • -t 不显示消息时间戳
  • -T 显示易读的时间戳格式
  • -u 显示用户空间消息
  • -w 等待新消息
  • --help 显示帮助信息
  • --version 显示版本信息
