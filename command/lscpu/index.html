lscpu

lscpu命令

功能描述

lscpu命令来自英文词组“list the CPU architecture”的缩写，其功能是用于显示CPU架构信息。lscpu命令会从/proc/cpuinfo文件中收集有关本机CPU架构的信息，并整理成易读的格式输出到Shell终端，运维人员可以很方便地了解到本机CPU数量、架构、线程、核心、套接字等重要指标信息~

语法

lscpu [参数]

参数说明

  • -a 显示全部的CPU信息
  • -b 仅显示在线CPU信息
  • -c 仅显示离线CPU信息
  • -e 显示扩展的可读格式
  • -h 显示帮助信息
  • -p 使用可解析的格式
  • -s 设置系统根目录
  • -V 显示版本信息
  • -x 显示十六进制掩码而非CPU列表信息
  • -y 显示物理ID而非逻辑ID
