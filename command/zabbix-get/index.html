zabbix-get

zabbix_get命令

功能描述

zabbix_get 是一个命令行工具，用于从 Zabbix 代理获取数据。

zabbix_get 是在server端用来检查agent端的一个命令，在添加完主机或者触发器后，不能正常获得数据，可以用zabbix_get来检查能否采集到数据，以便判断问题症结所在。

语法

zabbix_get [参数]

参数说明

  • -s 指定客户端主机名或者IP
  • -p 客户端端口，默认：10050
  • -I 指定源IP
  • -k 想要获取的key

参考示例

示例1:
获取主机的负载数据： [root@linuxcool ~]# zabbix_get -s 127.0.0.1 -p 10050 -k "system.cpu.load[all,avg1]"
示例2:
获取主机名： [root@linuxcool ~]# zabbix_get -s 127.0.0.1 -p 10050 -I 127.0.0.1 -k "system.hostname"
示例3:
获取监控nginx状态： [root@linuxcool ~]# zabbix_get -s 127.0.0.1 -p 10050 -k nginx.status[active]
